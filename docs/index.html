Features
Session Library
Every local session · archives · subagents · one window
CodexClaudeHermesAntigravity

CtxRelay finds sessions on its own — Codex journals, Claude Code and Claude Desktop projects, Hermes databases with all profiles, Antigravity IDE and app conversations. Filter by client or status, sort, and open any conversation with tool calls shown as collapsible entries.

From the detail panel: open the session in its desktop app, copy the resume command, reveal the file or jump to the project folder.

Library · conversation · relay buttons
Full-text Search
Search inside messages, not just titles · jump to the match
IndexSnippets

“Where did we fix that retry bug?” Type a word — CtxRelay searches the full text of every conversation across all clients, shows matching snippets right in the list and jumps straight to the message, even if it is hundreds of entries back. The index builds in the background and survives restarts.

Search · snippets · matched messages
Continue Elsewhere
Ran out of limits? Switch the client, keep the context
RelayNative

Click ⇄ Continue in Codex (or Claude, Hermes, Antigravity) and CtxRelay creates a new native session in that client with the whole history — messages, tool calls and their results. The new session shows up in the library, one click away from its app. Repeat an unchanged conversion and the existing copy is reused.

Handy when one assistant hits its usage limit mid-task, or when another one is simply better at the next step.

Install
Windows 10 / 11 · x64
1Install .NET 8 Desktop Runtime (x64) if you don't have it.
2Download CtxRelay.exe and run it — the library opens, the limits appear in the tray.
optClosing the window keeps CtxRelay in the tray. Turn on Start with Windows from the tray menu, or launch with --tray.
optNeeds WebView2 Runtime — already part of most Windows 10/11 installs.
Your data
Stays on your machineSessions are read from local files. No accounts, no cloud, no telemetry, no listening ports.
Read-only by defaultBrowsing never changes your history. Only relay (writes a new session) and delete (after a backup) touch anything.
Network, only for limitsUsage limits and token renewal talk to OpenAI and Anthropic with your own credentials. Nothing else goes out.
